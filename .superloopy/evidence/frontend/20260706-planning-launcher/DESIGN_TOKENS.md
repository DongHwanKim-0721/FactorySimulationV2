# Design Tokens Evidence

The token contract for this UI work is `DESIGN.md` at the repository root.

The planning workbook launcher uses the existing Tkinter operations-console direction:

- Slate application chrome.
- Light panel surfaces.
- Native ttk form controls.
- Compact 4 px spacing scale.
- No motion.
- Border and tonal depth only.

No new fixed color values were added in `planning_launcher.py`.
