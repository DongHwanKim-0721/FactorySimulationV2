# FactorySimulation Docs

Updated: 2026-06-10

This folder separates current truth from historical planning notes.

## Start Here

- `AGENT_CONTEXT.md`: read this first in a new Codex session.
- `CURRENT_STATE.md`: current product direction, implementation status, and next checks.
- `DECISION_LOG.md`: important product and architecture decisions with dates.
- `CHANGELOG.md`: user-visible changes by date.
- `manual-smoke-checklist.md`: manual Tkinter verification checklist.

## PRDs

- `prd/active/`: PRDs that are not implemented yet or are currently being designed.
- `prd/done/`: implemented PRDs that still explain current behavior.
- `prd/archive/`: superseded or historical PRDs preserved for context.

## Handoffs

- `handoffs/archive/`: historical session handoff notes. These are useful for archaeology, but they are not the current contract.
